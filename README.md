# PocketSkill

A mobile-first community marketplace prototype for discovering and offering small local services and practical skills.

## Current MVP
- Responsive phone-first interface
- Search by title, description, category, and area
- Category filters and saved listings
- Post a listing form with basic Indian mobile validation
- WhatsApp contact link
- Local browser storage for posts and favourites
- Sample data to demonstrate the experience

## Run
Open `index.html` in a browser, or enable GitHub Pages for this repository.

## Important prototype limits
Listings are stored only in the visitor's browser. They are not synchronized or visible to other people. Sample contact numbers are placeholders; replace them before any public launch. This is not yet a production marketplace.

## Roadmap
1. Add a shared backend and user authentication.
2. Add listing moderation, report/block controls, and spam prevention.
3. Add privacy-aware location/area filters and verified contact consent.
4. Test with a small local community before considering monetization.
5. Explore featured listings or local business promotion only after genuine usage.

## Zero-budget approach
Start with static hosting and local testing. A public multi-user service needs a backend; use a free tier only after reviewing its limits and privacy terms. Revenue is not guaranteed.
