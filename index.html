Settings & API

Add your own TMDB API Read Access Token to load live movie and series data. Without a token, the app displays demo titles.

Security: this is a browser app. A token entered here is stored only in this browser's local storage, but anyone who can access this device/browser may see or use it. Do not paste Firebase Admin keys, service-account keys, or other server secrets.

Get a token from your own TMDB account. The app uses movie metadata and links to official trailer searches or TMDB's legal watch-provider information; it does not host movies or bypass paid services.
